Packsmith 隐私政策

生效日期：2026-11-06 · 版本 v1
本政策适用于 Packsmith 工作台、分享页和云端账号功能。当前项目处于开发/测试阶段， 部分功能可能尚未部署。若后续上线主体、服务器或第三方服务发生变化，我们会更新本政策。

1. 我们是谁

Packsmith 是由个人开发者维护的 Minecraft 整合包编译器。当前没有独立公司主体。 联系渠道：GitHub Issues。

2. 我们收集哪些信息

  • 本地项目数据：整合包清单、配置、任务、导出文件，默认保存在你的电脑。
  • 账号信息：用户名、邮箱、密码哈希、登录会话；不保存明文密码。
  • 云同步数据：你主动同步的项目快照、revision 和冲突记录。
  • AI 功能数据：你提交的文字、图片、音频，以及生成结果；用于完成当次请求。
  • 支付订单信息：爱发电订单号、方案 ID、金额、留言；不接触银行卡/支付密码。
  • 运行日志：错误信息、请求时间、必要的安全日志；不主动记录 API Key 和明文令牌。

3. 使用目的

用于提供整合包生成、账号同步、AI 辅助、订单发货、故障排查和安全防护； 不将你的项目内容出售给第三方。

4. 第三方服务

  • GitHub Pages：托管公开分享页和构建产物，GitHub 可能记录访问 IP。
  • 爱发电：处理赞助/支付和订单回调。
  • DeepSeek、智谱等 AI 服务：处理你主动提交的 AI 请求。
  • 启动器/模组下载源：解析依赖和版本信息。

第三方服务按其自身隐私政策处理数据；请勿在 AI 请求中提交身份证、住址、支付密码等敏感信息。

5. 存储与保留

本地数据由你控制；云端账号和同步数据保存在部署的服务器数据库中。 我们按实现功能所需的最短期限保留，删除账号后删除或匿名化相关数据， 法律法规要求保留的除外。

6. 安全

密码使用 PBKDF2 哈希，令牌只存哈希，传输使用 HTTPS，权限按最小化原则配置。 但互联网服务无法保证绝对安全；发现泄露请通过 Issues 联系。

7. 未成年人

未满 18 周岁的用户应在监护人同意和指导下使用付费、账号和云同步功能。 未满 14 周岁的儿童不应自行注册或提交个人信息；如发现误收集，我们会删除。

8. 你的权利

你可以要求访问、更正、删除账号数据，或撤回授权。请通过 Issues 提交请求； 我们需要验证请求归属，避免误删他人数据。

9. 变更

政策更新会在本页发布，并标注生效日期。重大变更会通过页面提示。 继续使用即表示你接受更新后的政策。

本页是开发阶段的合规草稿，不构成法律意见；正式公开运营前建议由专业人士复核。
